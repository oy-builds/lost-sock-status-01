# Lost Sock Status Update

A make.fun entry for **Funniest Lost Sock Status Update**: a single status update of at most 120 characters, written in the voice of a lost sock that has ended up somewhere it should not be.

`main.ts` (Node 22, zero dependencies) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the kit's gate first: UTF-8, 1–120 characters, not only whitespace, a single line.

The entry:

> Update from inside the vacuum cleaner: I can see my twin from here. He's on a foot. Living the dream. Traitor.

Run it with:

```sh
node main.ts
```
